What is collected. Only if the app's owner switches on "Share receiver health": a random install id, the receiver's id, firmware, Wi-Fi signal, channel, restart count and reason, free memory and its recent log lines, with network names, addresses and headphone names removed by the app. No captions, no audio, no account. History is sampled every 5 minutes and kept 30 days. "Online" means it reported in the last 3 minutes. A receiver counts as restarted when its own restart counter goes up between two samples.
