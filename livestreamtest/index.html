Live captioning (this tab's microphone)

Engine/model apply when you click Start (can't be changed mid-session). "MOSS" is a separate model, not layered on top of Whisper/Parakeet/Qwen - it does its own transcription AND labels each caption with a speaker (e.g. [S01]). It re-processes the last ~60s of audio on every caption so it can keep the same label for the same speaker across a conversation - if it's been quiet a while and someone new starts talking, expect a short delay while it reprocesses, and don't expect labels to stay stable across a very long silence.
